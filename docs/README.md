## 推荐阅读路线

### 面试官或导师

1. 从项目首页打开在线系统并执行一次混合诉求对话；
2. 阅读[面试展示与项目讲解](portfolio-guide.md)中的三个技术点；
3. 通过 README 的关键代码导航定位到实际实现与测试。

### 开发者

1. 阅读[架构与运行约定](architecture.md)确认免费模式的数据边界；
2. 按根目录 README 完成本地启动；
3. 阅读[模型中心](model-studio.md)后再增加模型或任务类型。
